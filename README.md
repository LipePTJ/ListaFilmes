# ListaFilmes

Aplicação simples desenvolvida em **React** para gerenciar uma lista de filmes e acompanhar quais você já assistiu.

---

## 🚀 Funcionalidades

- Lista de filmes com título, gênero, ano e status.
- Botão para alternar entre **"Já assisti"** e **"Ainda não assisti"**.
- Alteração dinâmica da cor do cartão conforme o status.
- Contadores em tempo real:
  - 🎬 **Total de filmes**
  - ✅ **Assistidos**
  - ⏳ **Pendentes**

---

## 🛠️ Tecnologias

- **React** (Componentes Funcionais + `useState`)
- **Vite**
- **CSS3**
